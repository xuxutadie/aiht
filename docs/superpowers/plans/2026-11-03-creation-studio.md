# 作品创作台首版 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. 用户已明确要求开始，按当前会话分工执行，不再要求重复确认。

**Goal:** 完成有注册登录、固定引导、10点算力和Seedream后台配置的可运行网页。

**Architecture:** Python标准库HTTP服务、SQLite持久化、原生网页。服务端负责认证、方案确认、单图任务和扣点，浏览器不持有绘图密钥；本机初始化机构管理员。

**Tech Stack:** 已有Python3.14、SQLite3、HTML/CSS/JavaScript；不新增依赖、不修改.env、不自动提交Git。

**Spec:** ../../接口约定.md及本项目上级outputs/作品创作台_多巴胺概念/注册登录与创作额度规则.md。

## Global Constraints

- A桌面/手机视觉；名称作品创作台；所有沟通、注释、产品文案中文。
- 新用户首次赠送10点算力，单张成功扣1，失败返还，未知待核对，重复请求只能结算一次。
- 无语言模型；按预设问题和规则分支，模板整理提示词。
- 注册手机号、地区、学校、年级、姓名；密码安全存储，会话Cookie。
- 教师配置Seedream5.0Flash，学生不能读取密钥或他人数据。

## Review Focus

- 并发/重复生成不得透支和重复扣点。
- 学生跨账号访问方案、任务、图片和管理员配置必须拒绝。
- 超时和服务重启中的进行任务须保留待核对，不自动重新出图。
- 草稿修改后撤销确认，不能绕过后端直接生成。
- 手机输入、抽屉步骤和底部操作不能遮挡内容。
