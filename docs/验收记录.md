## 独立审查修复

1. 服务重复启动可能把运行中任务误转待核对：增加数据目录操作系统独占锁，成功监听后才恢复中断任务。
2. 关闭服务后排队任务仍可能发起新计费调用：取消未发出的任务并释放预占，已开始的任务完成后才释放实例锁。
3. 两个标签页同时改稿可能使提示词与方案快照不一致：预占事务内检查方案内容哈希。
4. 原请求结果丢失后，草稿修改或配置关闭影响找回：同请求编号优先返回原任务，禁止重新发出。
5. 启动器可能打开其他数据目录或假服务：核对数据目录身份与非测试标志，并拒绝非对象JSON。
