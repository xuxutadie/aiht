# 作品创作台：接口与开发约定

Python 3.11+ 标准库＋SQLite＋原生 HTML/CSS/JS。桌面与手机共用网页，不使用语言模型。部署只需本仓库源码和 Python，不需要相邻目录中的历史素材或工程。本文供开发维护时参考，首次部署阅读根目录的 README 即可。

维护约定：`main` 只保留当前 Python + SQLite 正式实现，本机和 Linux 使用同一份产品代码；旧云端实现留在 Git 历史中，不是新安装入口。旧数据有独立迁移工具。这样可以减少部署步骤、避免误用旧配置，同时保留原有账户与作品的迁移路径。

## HTTP JSON约定

成功响应为直接JSON对象；失败为{error:{code,message}}，HTTP状态正确。所有写请求JSON，Content-Type:application/json，服务端同源校验；凭证为HttpOnly会话Cookie，不使用localStorage存放密码、密钥或会话。

- GET /api/bootstrap -> {setup_required:bool, user:User|null, generation_configured:bool, test_mode:bool}
- POST /api/setup {name,phone,password} -> {user:User}，仅首次在本机初始化管理员并登录；公共地址启动前必须先初始化。
- POST /api/register {name,phone,password,region,school,grade,authorization_code} -> {user:User}；校验管理员发放的一次性8位数字授权码，成功后用码、建号及赠送10点原子完成并登录。
- POST /api/login {phone,password} -> {user:User}
- POST /api/logout {} -> {ok:true}
- GET /api/me -> {user:User}
- GET /api/plans -> {plans:Plan[]}
- POST /api/plans {title?:str,answers?:object} -> {plan:Plan}
- GET /api/plans/{id} -> {plan:Plan}
- PUT /api/plans/{id} {title,answers,step,confirmed?:bool} -> {plan:Plan}
- POST /api/plans/{id}/preview {} -> {prompt:str,missing:str[],summary:str}
- POST /api/generate {plan_id,request_key} -> {job:Job,user:User}，202。request_key由浏览器crypto.randomUUID生成；相同key不重复扣点。同一方案新一次出图用新key。
- GET /api/jobs/{id} -> {job:Job,user:User}
- GET /api/artworks -> {artworks:Artwork[]}
- GET /api/artworks/{id} -> {artwork:Artwork}
- PUT /api/artworks/{id} {reflection,description} -> {artwork:Artwork}
- GET /api/artworks/{id}/image -> 图片二进制，登录且本人/管理员可访问。
- GET /api/artworks/{id}/download -> 同一图片下载，不消耗算力。
- GET /api/credits -> {user:User,entries:Ledger[]}
- GET /api/admin/settings -> {configured:bool,provider:str,model:str,base_url:str,quality:str,watermark:bool,key_hint:str}，永不返回完整密钥。
- PUT /api/admin/settings {api_key?:str,model,base_url,quality,watermark} -> 脱敏配置；同一服务商空api_key保留旧密钥，切换服务商必须填写对应密钥。
- POST /api/admin/authorization-codes {count:int(1..100)} -> {codes:[...]}，仅生成时返回完整码。
- GET /api/admin/authorization-codes?limit=50&before=游标 -> 分页授权码使用记录，仅返回尾号和状态，不返回完整码。
- GET /api/admin/overview -> {users:User[],uncertain_jobs:Job[],stats:object}
- POST /api/admin/jobs/{id}/resolve {consume:bool,reason:str} -> {ok:true}

User={id,name,phone,region,school,grade,role:'student'|'admin',credits:int,reserved_credits:int,available_credits:int,unlimited_credits:bool,created_at}。credits是尚未实际消耗的有限算力点数，available=credits-reserved。管理员的unlimited_credits为true，保留历史数字余额但新任务不再预留和扣点。学生只看本人，管理页面只供管理员；管理员汇总的remaining_credits只统计学生余额。
Plan={id,user_id,title,answers:object,step:int(0..6),confirmed:bool,created_at,updated_at}。
Job={id,user_id,plan_id,status:'queued'|'running'|'succeeded'|'failed'|'uncertain'|'settled',error_message:str|null,artwork_id:str|null,unlimited_credits:bool,created_at,updated_at}。任务是否免扣由服务端创建任务时固定的账本记录决定；旧任务无免扣标记，沿用原预留结算规则。管理员免扣任务仍保留任务、结算和异常核对记录。
Artwork={id,user_id,job_id,plan_id,title,image_path,mime,width,height,prompt,answers:object,description,reflection,created_at}。API返回的image_path改为/api/artworks/{id}/image，绝不暴露本地绝对路径。原图保存data/artworks，用唯一随机文件名。
Ledger={id,kind,delta,balance_after,job_id,note,created_at}。

## 创作答案字段（七步）

0读懂赛题：competition_name,competition_theme,requirements,task_understanding；
1确定主题：theme,reason；
2说明表达：message,message_detail；
3设计画面：subject,scene,action,details,subject_framing,scene_distance,ratio('1:1'|'4:3'|'3:4'|'16:9'|'9:16'),style('动漫'|'写实'|'水彩'|'拼贴'|'版画'),style_reason；
4提炼创新并确认：innovation_type('新的组合'|'不同的视角'|'特别的用途'|'新的故事'),innovation,innovation_visible,可选 custom_prompt；
5生成修改：只在前面字段齐全、学生勾选自查并确认后可出图；
6作品说明：生成后reflection、description，在Artwork中保存。模板预填，学生可改；无文字模型。
required字段：task_understanding,theme,reason,message,message_detail,subject,scene,action,details,ratio,style,style_reason,innovation_type,innovation,innovation_visible。比赛要求可先用“未来城市与自然共生”练习，必须标明可编辑练习规则，不能伪装真实比赛。

## 模块分工与Python接口

核心存储位于 studio/store.py、studio/_store_database.py、studio/_store_jobs.py、studio/auth.py 及相关 tests。Store(db_path:Path) 自动初始化 SQLite，并发连接按操作创建；全部写事务 BEGIN IMMEDIATE，密码使用 scrypt，数据库查询参数化。
Store接口：has_admin(); create_user(profile:dict,password:str,role='student')->User; authenticate(phone,password)->User|None; create_session(user_id)->str; get_user_by_session(token)->User|None; delete_session(token); get_user(user_id)->User; list_users()->list; create_plan(user_id,title,answers=None)->Plan; list_plans(user_id); get_plan(user_id,plan_id); save_plan(user_id,plan_id,answers,step,confirmed=False,title=None)->Plan; reserve_generation(user_id,plan_id,request_key,prompt,options)->Job; mark_job_running(job_id); get_job(user_id,job_id)->Job; complete_generation(job_id,artifact:dict)->Artwork; fail_generation(job_id,message,uncertain=False); list_artworks(user_id); get_artwork(user_id,artwork_id); update_artwork(user_id,artwork_id,reflection,description); ledger(user_id); list_uncertain_jobs(); resolve_uncertain_job(job_id,consume,admin_user_id,reason); mark_interrupted_jobs_uncertain()。可增方法，但不要改已约定签名。

绘图适配位于 studio/provider.py、studio/secrets.py 及测试。SecretSettings(data_dir:Path).public() 返回脱敏配置，.get() 只在后台读取完整密钥。支持火山方舟 Seedream 5.0 Flash（默认 https://ark.cn-beijing.volces.com/api/v3）与 OpenAI-HK GPT Image 2（https://api.openai-hk.com/v1）；服务地址和模型受白名单约束。密钥 Windows 使用 DPAPI，其他平台使用私有权限文件，始终不输出完整密钥。上游超时、未知结果不自动重试收费调用，图片格式和大小需校验。默认单图，仅调用绘图服务，不调用语言模型。模拟绘图只在独立测试环境启用。

server.py、studio/web.py 提供 HTTP 服务；studio/plans.py 负责七步计划与提示词；studio/jobs.py 负责生成调度；public/ 是共享网页。部署、用户数据与源码分离，正式上线须配置有效 HTTPS。


## 实现时补充

bootstrap额外返回service、version、instance_id用于启动器识别同一份数据，instance_id是路径规范化摘要而非实际路径；test_mode为true的服务不能被正式启动器复用。
Store.reserve_generation支持expected_plan_hash可选参数，用于事务内校验提示词与方案快照一致；get_job_by_request优先找回旧请求。record_provider_result保存上游请求编号和用量，仅上游编号进入公开Job，用量仅后台内部读取。实例锁先于数据库操作，成功监听后才恢复中断任务；停止时取消未发出任务，待活动任务完成结算后释放锁。
