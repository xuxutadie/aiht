# Cloudflare 正式在线版：设计与接口

用户已明确不使用R2，并已允许安装Wrangler。正式Worker绑定D1、Queue、私有SQLite Durable Object运行服务与ASSETS；图片分片规则见《D1图片存储约定.md》。

用户已确认将后台和数据库适配为 Cloudflare 正式在线版。页面继续使用仓库的 public，云端后台放在 cloudflare，默认使用 workers.dev HTTPS 地址。

## 存储与任务

- Workers 提供同源网页与 /api，D1 保存账户、会话、方案、任务、作品元信息、图片分片和算力账本。图片经本人/管理员鉴权后，通过私有DO逐片读取。
- Queue 执行单图任务。重复投递只能由 queued 原子领取一次；结果未知不自动重发收费请求。超时、网络不确定和中断任务保留算力等待人工核对。
- 新账户10点，成功单张扣1点，明确失败释放预留。全部预留和真正耗尽分别提示。D1 使用条件 SQL 与 batch 原子提交，不在请求之间维持事务。
- 当前保留所有成功作品，最近4张保留规则尚未启用。本轮不自动迁移本机真实账号、API 配置或图片。
- 公开云端初始化管理员需要一次性初始化口令 ADMIN_SETUP_TOKEN；未配置口令时不允许任何访问者建立管理员。口令只通过 Workers Secret 提供。
- CONFIG_ENCRYPTION_KEY 为32字节随机主密钥，使用 Workers Secret；后台设置的绘图密钥以 AES-GCM 加密后存 D1，接口始终只返回脱敏提示。
- 绘图服务固定支持火山方舟Seedream5.0Flash与OpenAI-HK的gpt-image-2。通过规范化base_url区分服务商，切换时必须显式填写对应密钥。quality保存在既有JSON配置中，不增加表字段。
- 任务options保存服务地址、模型、清晰度、水印与配置指纹；指纹对这些参数和密钥计算SHA256，不保存明文密钥。Queue读取当前配置后先比对指纹；配置已变更则在付费调用前明确失败并释放预留。旧无指纹任务仅按原Ark配置兼容，不能转送HK。
- 密码继续兼容 Python 的 scrypt$16384$8$1$盐hex$摘要hex；会话 Cookie 为 HttpOnly、Secure、SameSite=Strict。

## 模块职责

- contracts.js：DomainError、常量、通用文本检查。
- crypto.js：hashPassword(password)、verifyPassword(password,encoded)、sha256(text)、constantTimeEqual(a,b)、encryptSecret(text,key)、decryptSecret(payload,key)。sha256 返回hex；加密返回可JSON序列化对象，解密返回原字符串；key为base64编码32字节主密钥。
- auth.js：validateProfile(profile,role)，与 Python 的五项资料规则一致。
- plans.js：DEFAULT_ANSWERS、sanitizeAnswers、missingFields、buildPrompt、buildSummary，与 Python 模板一致，不调用语言模型。
- provider.js：validateSettings(payload,current)、publicSettings(config)、generateImage(config,prompt,options)。config含model/base_url/watermark/api_key；generateImage返回 {data:Uint8Array,mime,width,height,usage,upstream_request_id}；ProviderError含uncertain/requestId。
- store.js：Store(D1Database)，所有公开输出去掉密码/会话摘要/原始usage。Queue和HTTP使用同一个Store。
- image-storage.js：D1ImageStorage(db)与getImageStorage(env)，正式默认使用D1，测试可显式注入IMAGE_STORAGE。
- runtime-services.js：AihtRuntimeServices及私有Namespace helpers。密码服务串行执行scrypt，图片按对象key分配服务实例、流式读取；不使用DO持久存储保存密码或图片。公共HTTP不暴露内部路由，绑定缺失时返回503。
- queue.js：handleQueue(batch,env)，handleScheduled(env)。使用env.DB、getImageStorage(env)、env.CONFIG_ENCRYPTION_KEY。测试可显式传入第三个参数generateImageOverride；正式导出调用不传覆盖。
- index.js：默认导出 fetch/queue/scheduled；HTTP角色鉴权、同源校验、限流、静态资源与私有图片。

## Store 方法（全部 async）

基本：hasAdmin(); createUser(profile,passwordHash,role='student')->User; findUserByPhone(phone)->内部User含password_hash; getUser(id)->User; listUsers()->User[]。

会话：createSession(userId,tokenHash,expiresAt); getUserBySession(tokenHash)->User|null; deleteSession(tokenHash)。expiresAt为Unix秒。

方案：createPlan(userId,title,answers)->Plan; listPlans(userId); getPlan(userId,id); savePlan(userId,id,{title,answers,step,confirmed})->Plan。Plan增加内部revision整数用于预占时检查快照版本；浏览器可忽略它。

任务：getJobByRequest(userId,requestKey)->Job|null; reserveGeneration(userId,planId,requestKey,prompt,options,expectedRevision)->Job; getJob(userId,id)->公开Job; getJobInternal(id)->内部Job含prompt/options/answers/title；claimJob(id)->内部Job|null（queued原子改running）；recordProviderResult(id,requestId,usage={}); completeGeneration(id,artifact)->Artwork|null（仅running可成功一次）；failGeneration(id,message,uncertain=false,onlyQueued=false); listUncertainJobs(); resolveUncertainJob(id,consume,adminId,reason); markStaleJobsUncertain(cutoffISOString)。

reserveGeneration返回的非枚举newly_created仅供当前HTTP调用判定。只有唯一创建者且任务仍queued时才发送队列；同请求号恢复不再投递。投递报错使用onlyQueued=true，只冻结尚未领取的任务，不改写正在执行或已完成任务。预占同时检查320MiB图片编码预算，不足时明确拒绝且不调用模型。

成功产物：artifact={id,image_path,mime,width,height,description,reflection}，id由Queue生成，图片在D1完整保存后才结算。Store使用任务快照填充用户、主题、prompt、answers。分片保存失败或数据库成功状态无法确认时，标为结果未知，不自动再次调用模型。

作品：listArtworks(userId); getArtwork(userId,id); getArtworkForAdmin(adminId,id); updateArtwork(userId,id,reflection,description); ledger(userId)。内部image_path为D1图片对象key，公开接口转换为鉴权图片地址。

配置：getSettings()->对象|null; saveSettings(encryptedConfig)->void；键名固定generation-settings。encryptedConfig结构由HTTP/Queue约定为{model,base_url,watermark,encrypted_key}，encrypted_key为encryptSecret返回的对象。

限流：checkRateLimit(key,limit=60,period=60) 使用D1按时间窗口计数，超限抛429；key使用IP摘要，不保存明文IP；cleanupRateLimits()供定时任务调用。

## HTTP 兼容

沿用根目录 docs/接口约定.md 的路径和请求字段。bootstrap增加setup_token_required，setup请求增加setup_token字段；本机Python入口不要求此字段。

所有写请求必须是JSON，Origin必须等于当前请求URL的origin（可选PUBLIC_URL限制正式域名），拒绝cross-site。账号会话不放localStorage；图片不公开，不记录完整请求/手机号/API密钥。
