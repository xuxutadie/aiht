# D1 转 Python 数据目录

适用于已确认的腾讯云北京服务器迁移。工具为 `scripts/migrate_d1.py`，只使用 Python 标准库和本项目已有图片检查函数，不调用绘图或语言模型接口。

## 来源与输出

使用 Cloudflare 官方 Wrangler 导出的业务 SQL。必须包括 `users`、`plans`、`jobs`、`artworks`、`image_objects`、`image_chunks`、`ledger`、`audit` 八张表。导出时排除 `settings`、`sessions`、`rate_limits`；即使来源含这些表，工具也不将其写入目标。

启用注册授权码后，还须导出 `authorization_codes`：迁移保留摘要、尾号、生成者、使用者及使用时间，未使用码仍可注册，已使用码仍不能重用。没有该表的旧快照仍可迁移，目标新增空表；已有此表时不得在导出中遗漏。包含自增ID的导出可能带有SQLite内部序号表，工具仅允许必要的序号读写，不因此开放其他表的删除或任意更新。

SQL、转换目录和数据包均含私人资料，必须位于受保护目录，不得加入 Git、公开网站根目录、公开下载链接或普通日志。Linux 目录权限为 700、文件为 600；Windows 应在父目录设置仅本人和 SYSTEM 可访问的 ACL。临时源 SQLite 在 SQL 的同一父目录创建并随本次操作清理。

输出是一个尚不存在的新数据目录：

- `creation.sqlite3`：现有 Python 表结构，保留账号 ID、scrypt 哈希、角色、原余额、完整账本、草稿答案、手改提示词、任务与作品快照、说明和反思。
- `artworks/`：私有图片文件，以原作品编号命名；不放入网页静态目录。
- `migration-manifest.json`：来源 SHA-256、数量/余额汇总、图片大小与 SHA-256，不含姓名、手机号、密码哈希、提示词正文或 API 密钥。

不重新赠送算力，不迁移登录会话，不复制或解密绘图配置。负责人需在新后台重新登录并填写 API 密钥。

## 检查、转换和复核

在发布包目录运行，路径按实际私密文件位置替换：

```text
python scripts/migrate_d1.py /private/d1-business.sql --check-only
python scripts/migrate_d1.py /private/d1-business.sql /private/data-candidate
python scripts/migrate_d1.py /private/d1-business.sql /private/data-candidate --verify
```

`--check-only` 只验证来源结构、账户/账本与任务终态，并输出汇总；它不解码图片，输出明确标记 `image_bytes_verified=false`。正式转换才逐片验证图片索引、规范 base64、分片长度、总大小、SHA-256、实际格式和尺寸，以及作品/用户/任务归属。复核模式在新服务启动前使用，只读逐字段比较所有迁移业务行并重算目标图片哈希，不修补差异。

工具拒绝覆盖任何已有目标目录。重复转换应选择一个新的候选目录；这可避免把旧快照覆盖正式运行数据。任务的原 `request_key` 保留，`request_hash` 依据原任务快照重算；原请求恢复会返回历史任务，不重新绘图、不重复结算。

## 必须先处理的情况

只要存在 queued/running/uncertain 任务、非零预留算力、未完成/孤立图片、断开的归属引用、账本余额不一致、缺失预留/扣点/人工核对流水，工具就拒绝发布目录。不要手工把预留归零或删除任务以通过检查。应先在原站核对已发生的上游收费和生成结果，完成正确结算，再重新导出。

SQL 导入只允许本项目普通业务表、索引及数据，禁止 ATTACH、触发器、虚拟表、扩展及任意函数。仅开放 Wrangler 文本转储使用的 `replace` 和 `char`。

## 演练与正式切换

原站仍可写入时导出的快照只能用于演练，不得当作最终生产数据。正式切换前须进入短暂维护窗口，阻止新生图和业务写入，确认没有在途或待核对任务，重新导出、转换、复核后再启动新服务。备案和真实网络验收通过后切换域名。Cloudflare 保留回退，演练和转换不会自动修改旧站、DNS 或删除数据。

合成测试命令：`python -m unittest tests.test_migrate_d1 -v`。测试使用虚构账号和本地 PNG，不接触真实绘图接口。
