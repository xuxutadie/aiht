# 腾讯云国内部署

适用于已确认复用的北京服务器：OpenCloudOS 9.4、Python 3.11.6、现有宝塔 Nginx。
后台使用 Python 标准库；不安装 pip 包，也不需要 Node 构建。源码和私有数据分开放置。

## 目录与运行账号

- `/opt/aiht-creation-studio`：只读应用源码，由 root 管理。
- `/var/lib/aiht-creation-studio`：账号、SQLite、配置和私有图片，由 systemd 的 `StateDirectory` 管理，运行账号可读写，目录权限 0700。
- `aiht`：systemd `DynamicUser` 动态运行身份，不创建永久登录账号、SSH 凭据或 sudo 权限；数据目录的归属由 systemd 管理。
- 原项目 `/www/wwwroot/xinqidian`、旧数据库和 Nginx 配置先备份；不格式化、不重装系统。
- 已有 Nginx、宝塔和 MongoDB 不因迁移而卸载；仅在服务归属核对后停用旧 `xinqidian` 进程。

发布包由 `python scripts/build_mainland_release.py --output <新的发布包.tar.gz>` 创建。
包内 `RELEASE-MANIFEST.json` 记录每个文件的 SHA-256。包不含用户数据或密钥。
生产数据经专用转换工具单独导入、对账与安全传输，不能用测试数据覆盖。

## 启动前条件

1. 完成迁移数据核对：保留原账号密码哈希、余额、账本、草稿、任务和作品，全部图片大小与 SHA-256 一致；迁移会话失效。
2. 原站没有未处理的在途任务，切换窗口内停止接受新生图，避免两边生成或结算。
3. 运行账号能读取源码且只可写自己的数据目录。服务端不在公网监听 8321。
4. 原管理员已在导入库中。`server.py --public-url` 会拒绝启动没有管理员的空库；不要通过新增初始化管理员绕开。
5. API 密钥由负责人在新后台重新填写；不从 Cloudflare 导出配置主密钥，不把密钥放进命令、发布包或运行日志。

`aiht-creation-studio.service` 使用 systemd 托管单进程。启动参数中的正式地址决定跨站校验和 Secure Cookie，内部验收也保留这一地址。用本机 HTTP 命令验收时明确设置 `Host: xqd-ai.cn` 和写入请求 `Origin: https://xqd-ai.cn`，不要放宽生产校验。浏览器完整验收须使用有效 HTTPS。

安装 unit 前先确认 `python3` 的绝对路径与版本及 systemd 对 `DynamicUser`、`StateDirectory` 的支持。先把迁移库放入预定的 StateDirectory，初次启动时 systemd 将管理其运行身份归属；不要用 `chmod 777` 处理权限问题。复制 unit 后执行 systemd 的配置重载和服务启动，查看本机 `/api/bootstrap`。服务配置使用 SIGINT 优雅停止，最多等待240秒，不因重启自动重试付费绘图；切换前仍应先处理所有在途任务。

unit 将应用内存软阈值设为600MiB、硬上限900MiB，为2GB主机上的宝塔、Nginx及系统留出空间。达到硬上限可能导致进程被系统终止；恢复后必须核对在途任务和预留算力，不得因页面未出图就重新发送付费请求。该限制只是资源保护，不保证任何固定人数或原图大小下都能成功。

## 备案前和正式切换

备案前保持应用只监听 127.0.0.1；不改 DNS，不新开公网端口，不直接套用正式 Nginx 样板。
`xqd-ai.top` 的旧备案记录不会自动覆盖 `xqd-ai.cn`，需要按腾讯云核验结果处理新域名备案。

`nginx-local-check.conf.example` 是独立的本机预验收样板，只监听 `127.0.0.1:8088` 并转发到 `127.0.0.1:8321`。先检查8088未被占用，Nginx配置检查通过才重载。用服务器本机命令读取首页和 bootstrap；写入测试还要带 `Origin: https://xqd-ai.cn`。这不是公网地址，也不能用明文HTTP浏览器的Cookie测试替代正式HTTPS登录验收，Secure Cookie策略保持不变。

备案完成、证书就绪和内部测试通过后，再单独审核 `nginx.conf.example` 的证书路径、域名与现有站点关系。
先执行现有 Nginx 的配置检查，检查通过才重载。DNS 正式切换前记录 Cloudflare 原解析，保留原站以便回退。
由于目标是国内直连，不能在切换后仍让全部网页、API 和图片绕经境外反向代理。

## 60 人模拟验收

运行 `python scripts/mainland_load_test.py --clients 60 --image-mib 2 --output <测试报告.json>`。
该工具只会启动本机临时数据库和固定假图片服务，没有外部目标地址参数，不调用任何真实绘图接口。
它测试集中注册与登录、保存及确认草稿、提交任务、轮询、并发下载、账户隔离和请求幂等；退出后停止临时服务并清理测试数据。

报告单列首次响应错误、繁忙后重试、最终业务结果、余额/任务对账和进程内存。出现 503、超时或重试时不得写成“60 人全部无错误”。
本机压测不包含 4Mbps 公网瓶颈，也不代表真实绘图速度。60 人各下载 2MiB，总计约 120MiB，在 4Mbps 理论上至少约 4.2 分钟才能传完；实际还受协议、线路和其他流量影响。
真实教学网络、手机流量和上游服务的连通性另行验证；真实付费绘图不属于这个模拟工具的验证内容。
