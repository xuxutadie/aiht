# 作品创作台

面向小学和初中学生的 AI 创作平台。学生通过七步引导说明创作主题、表达意图、画面设计与创新点，确认方案后再生成图片，并为作品撰写说明。

**本仓库只维护一个正式版本：Python + SQLite + 浏览器网页。** 本机体验和 Linux 服务器部署使用完全相同的功能代码。不需要安装 Node.js、MySQL、第三方 Python 包或语言模型。

## 第一步：选择你要做什么

| 使用场景 | 操作方式 |
| --- | --- |
| 在自己的电脑试用 | 按下面的一键启动步骤操作 |
| 让学生通过互联网访问 | 按 [腾讯云 / Linux 服务器部署教程](deploy/mainland/部署说明.md) 操作 |
| 已经部署，需要更新代码 | 阅读同一份服务器教程中的更新与备份章节，不覆盖原数据 |

推荐第一次使用时先在自己电脑体验。不要把本机临时地址当成学生可访问的正式网址。

## 第二步：在自己电脑运行

1. 在 GitHub 的 `main` 分支点击 **Code → Download ZIP**，下载并解压全部源码；也可以执行 `git clone https://github.com/xuxutadie/aiht.git`。
2. 安装 **Python 3.11 或更高版本**。Windows 安装时勾选添加 Python 到 PATH。终端执行 `python --version` 确认安装成功。
3. Windows 双击项目根目录的 **启动作品创作台.cmd**，或在项目根目录运行：

```bash
python launch.py
```

在 macOS / Linux 本机终端通常使用 `python3 launch.py`。默认浏览器地址为 <http://127.0.0.1:8321/>；端口已被占用时以启动提示中的实际地址为准。

## 第三步：创建管理员并配置绘图

1. 首次打开页面，按提示创建自己的管理员账号。
2. 进入「后台设置」，选择豆包 Seedream 5.0 Flash 或 OpenAI-HK GPT Image 2，输入自己的绘图 API 密钥。接口默认地址和模型会自动填写；切换服务商需要对应的密钥。
3. 在「注册授权码」中生成 8 位数字授权码，完整码只在生成时显示，须及时复制保存，再单独发放给学生。
4. 学生凭码注册。每个码仅能成功注册一次，注册成功后该码失效；原有账号照常登录，不需要补码。

未配置 API 时也可以创建、保存和预览创作方案，但不能调用模型生图。真正的绘图费用由所选服务商收取。详细操作见 [平台使用说明](使用说明.md)。

## 当前完整功能

- 学生注册、登录、账号数据隔离和一次性授权码；管理员不限累计发码数量。
- 七步创作框架、主角展示范围、场景景别、比例、风格、创新引导、可手动修改的提示词和创作自查。提示词整理不调用语言模型。
- 学生注册赠送 10 点算力，每成功生成一张扣 1 点；明确失败不扣，未知结果待人工核对；额度耗尽时显示联系管理员的提示。
- 管理员无限平台算力，生成不预留、不扣点，仍按实际绘图 API 用量付费。
- 草稿、作品、原图、提示词、作品说明和反思持久保存；电脑和手机采用同一响应式页面。

目前保留所有成功作品，还没有启用每位用户仅保留最近四张的限制；当前未内置充值或支付功能。

## 数据与配置

- 本机数据默认保存在 `data/`，服务器数据放在私有目录，与源码分开。首次启动自动建库，不需要手工建表或导入其他用户的数据库。
- API 密钥在自己的后台配置，不放在 GitHub、命令行或发布包中。Windows 的密钥由当前 Windows 用户的 DPAPI 保护；换电脑后重新配置。
- 正式服务器必须使用自己的域名、HTTPS 证书及适用的备案信息。启动参数 `--icp-number` 用于显示本站备案号；未配置时不显示别人的号码。
- 更新前停止服务并备份整个私有数据目录；更新只替换程序源码，不覆盖数据库、作品和密钥。不要上传 `data/`、配置文件及个人资料。

## 验证

在仓库根目录运行：

```text
python -m unittest discover -s tests -v
```

自动测试使用临时数据库和模拟绘图响应，不调用付费绘图服务。独立浏览器验收入口为 `tests/run_preview.py`，它使用明确标注的测试图片，不代表真实 Seedream 绘图效果。

负责前端开发的人员还可在已安装 Node.js 24 的环境中运行 `node --test tests/frontend/*.test.mjs`，无需安装 npm 包。普通使用和正式部署不需要 Node.js。

## 代码结构

- `server.py`：本机和服务器共用的 HTTP 后台入口。
- `launch.py`、`启动作品创作台.cmd`：便捷启动与服务复用。
- `studio/`：账号、会话、方案、图片任务、绘图接口及 SQLite 数据保存。
- `public/`：网页界面、七步创作与算力提醒。
- `deploy/mainland/`：Linux 服务器部署模板和安装教程。
- `scripts/`：发布包构建、模拟验收及高级旧数据迁移工具。
- `tests/` 与 `docs/`：开发验证及技术说明（首次部署不需要操作其中的文件）。

只有曾使用旧版 Cloudflare 数据的运营者，才需要参考 [旧数据迁移说明](docs/migration/旧Cloudflare数据迁移.md)。新部署直接创建空数据库即可。
