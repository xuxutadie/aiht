# 作品创作台

面向小学和初中学生的 AI 绘图创作工具。学生通过七步引导说明创作主题、表达意图、画面设计与创新点，确认方案后再生成图片，并为作品撰写说明。

## 已实现功能

- 手机号和密码注册登录，登记姓名、地区、学校与年级；学生只查看自己的方案和作品。
- 七步创作流程：读懂赛题、确定主题、说明表达、设计画面、提炼创新、生成修改、作品说明。
- 使用固定问题、条件提示和模板整理绘图提示词，不调用语言模型。
- 管理员在后台配置豆包 Seedream 5.0 Flash 绘图接口；完整 API 密钥不返回学生端。
- 首次注册赠送 10 点算力；每张成功作品消耗 1 点，明确失败不扣；结果未知时预留并由老师核对。
- 算力用完时弹出“请联系管理员进行补充算力”，并在生成区域保留提示。
- 方案、作品、提示词、说明和反思持久保存，支持查看与下载原图。
- 电脑和手机共用的响应式界面。

当前保存所有成功生成的作品；“每位用户只保留最近 4 张”的上限尚未启用。补充算力弹窗用于引导联系管理员，当前未实现充值或支付功能。

## 本机运行

使用 Python 标准库和 SQLite，无第三方 Python 依赖。本机验证版本为 Python 3.14。

Windows 用户进入仓库目录，双击 **启动作品创作台.cmd**。也可在该目录运行：

```text
python launch.py
```

默认访问地址：<http://127.0.0.1:8321/>。启动器会复用同一数据目录的服务；默认端口被占用时会寻找可用端口。

第一次打开后，由机构负责人创建管理员，再进入“后台设置”配置自己的绘图 API。学生使用各自账户注册登录。未配置绘图接口时，可以填写和保存创作计划。

更多操作说明见 [使用说明](使用说明.md)。

## 数据与配置

首次运行自动在 `data/` 中创建 SQLite 数据库、作品文件和配置。Windows 的 API 密钥配置使用当前 Windows 用户的 DPAPI 保护。换电脑或 Windows 用户后，需要重新配置密钥。

仓库仅保存程序源码、测试和文档。运行数据、真实用户资料、API 配置、生成图片、日志和缓存均在忽略范围内。备份时先停止服务，再备份本机 `data/` 目录。

本版以本机访问为默认。其他设备访问与公网部署需要另行配置服务器、HTTPS 和备份。

## 验证

在仓库根目录运行：

```text
python -m unittest discover -s tests -v
```

自动测试使用临时数据库和模拟绘图响应，不调用付费绘图服务。独立浏览器验收入口为 `tests/run_preview.py`，它使用明确标注的测试图片，不代表真实 Seedream 绘图效果。

## 代码结构

- `server.py`：本机服务入口。
- `launch.py`、`启动作品创作台.cmd`：便捷启动与服务复用。
- `studio/`：账号、会话、方案、图片任务、绘图接口及数据持久化。
- `public/`：网页界面、七步创作与算力提醒。
- `tests/`：自动测试和独立浏览器验收环境。
- `docs/`：接口与验收记录。
